This is the Open Source UI version of the **Marketplace Starter Kit**.
It includes the mobile-first layout, Tailwind configuration, and UI components.

## What Lite includes
Front end only. Every page runs on built-in demo data; no page calls a backend API:
✅ Swipe deck, matches, chat screens and profile page
✅ Multi-step onboarding and personality-test flows
✅ A `useChatSockets` hook and service modules (`src/services/`) that return demo data

## 🚨 What Lite does not include
❌ A backend connection: no login, signup or account data (the service modules only return demo data)
❌ Live chat: messages are not sent or received in real time
